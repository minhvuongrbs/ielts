## Goal
Create an interactive page teaching 7 IELTS reading skills with bilingual content and mini-practice exercises. Content extracted from the Oxford IELTS Preparation and Practice textbook. Lives at `reading/skills/`.

## Skills (from the book)
1. Skimming — read quickly for main topic/purpose
2. Scanning — find specific information without reading everything
3. Understanding vocabulary from context — guess meanings from surrounding words
4. Main ideas and details — distinguish main message from supporting facts
5. Identifying main ideas in longer text — find main idea per paragraph
6. Distinguishing details from main ideas — know that details = examples/facts/evidence
7. Understanding the writer's viewpoint — identify opinion vs facts
